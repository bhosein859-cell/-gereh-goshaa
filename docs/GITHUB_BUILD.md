# ☁️ ساخت فایل نصبی با گیت‌هاب — راهنمای قدم‌به‌قدم

> بدون نصب هیچ نرم‌افزاری؛ همه‌چیز روی سرورهای گیت‌هاب ساخته می‌شود.
> سازنده: حسین بختیاری

## قدم ۱ — حساب گیت‌هاب (یک‌بار)
1. بروید به `github.com` و **Sign up** را بزنید
2. با ایمیل ثبت‌نام و ایمیل را تایید کنید (۲ دقیقه)

## قدم ۲ — ساخت مخزن
1. دکمه **+** بالای صفحه → **New repository**
2. در قسمت Repository name بنویسید: `gereh-gosha`
3. گزینه **Private** یا Public — فرقی ندارد → **Create repository**

## قدم ۳ — آپلود پروژه (بدون نیاز به گیت!)
1. وارد مخزن شوید → روی **uploading an existing file** کلیک کنید
2. **محتویات پوشه‌ی `gereh_gosha`** را انتخاب و درگ کنید:
   - پوشه‌های `lib` و `assets` و `docs` و `.github`
   - فایل‌های `pubspec.yaml` و `README.md` و `CHANGELOG.md` و `.gitignore`
3. پایین صفحه **Commit changes** را بزنید
4. ⚠️ مطمئن شوید پوشه‌ی `.github` آپلود شده (همین فایل ساخت است!)

## قدم ۴ — اجرای ساخت
1. تب **Actions** بالای مخزن را باز کنید
2. اگر پیامی درباره‌ی فعال‌سازی دیدید، **I understand my workflows** را بزنید
3. از ستون چپ: **ساخت نصبی اندروید و ویندوز** → دکمه‌ی **Run workflow** → دوباره **Run workflow**

## قدم ۵ — دانلود فایل‌های نصبی
1. چند دقیقه صبر کنید تا دو کار (اندروید و ویندوز) سبز ✅ شوند
2. روی آخرین اجرا کلیک کنید
3. پایین صفحه، بخش **Artifacts**:
   - `GerehGosha-1.0.0-Android` ← فایل **apk** برای گوشی
   - `GerehGosha-1.0.0-Windows` ← **زیپ قابل‌حمل** + بسته **msix** ویندوز

## نصب
- **اندروید:** فایل apk را به گوشی ببرید و نصب کنید (اجازه‌ی نصب از منابع ناشناس)
- **ویندوز:** زیپ را باز کنید و `gereh_gosha.exe` را اجرا کنید (نسخه‌ی قابل‌حمل، بدون نصب)

## نکات مهم برای کاربران ایران
- خود گیت‌هاب معمولاً باز است؛ اگر باز نشد، فقط برای آپلود اول از فیلترشکن استفاده کنید — بعد از آن نیازی نیست
- هر بار که فایل‌ها را عوض کنید و دوباره آپلود کنید، ساخت **خودکار** اجرا می‌شود
- فایل‌های Artifacts تا ۶۰ روز نگه داشته می‌شوند؛ بعد از آن دوباره Run بزنید

## اگر ساخت قرمز ❌ شد
روی همان اجرا → روی کار قرمز کلیک کنید → متن خطا را کپی کنید و برای من بفرستید؛ معمولاً یک تنظیم کوچک است.
